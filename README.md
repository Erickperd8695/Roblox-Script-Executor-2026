The XCutors loader and package organization are free. However, several of the bundled executors (like Synapse Z and Wave) are paid tools that require you to purchase a valid license key from their respective developers to activate and use them.

### Which Windows versions are supported?

XCutors is designed for modern Windows operating systems, including Windows 10 and Windows 11. It relies on frameworks and libraries that are fully supported on these platforms.

### My anticomponent flagged the file as malicious. What should I do?

This is a common occurrence with software in this category. The detection is typically a false positive due to the injection and memory manipulation techniques used by the executors. You may need to add an exception in your anticomponent software to use the package.

### Does this work on the Microsoft Store version of Roblox?

No, XCutors is designed exclusively for the Windows Desktop version of Roblox downloaded from the official website. The Microsoft Store version has different security models and is not compatible.

### Where can I find scripts to run?

After injecting an executor, you can use built-in script hubs or paste Lua code directly. Many script repositories and communities exist online where users share and discuss custom scripts for various games.
